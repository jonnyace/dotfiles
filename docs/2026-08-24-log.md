# 2026-08-24

## One-line installer

`install.sh` bootstraps a new macOS or Arch Linux machine with Chezmoi:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/jonnyace/dotfiles/main/install.sh)"
```

The script installs missing git/chezmoi (and Homebrew on macOS), then runs
`chezmoi init --apply --interactive`. Package installation is a Chezmoi
`run_onchange_before_` script, not a sidecar `bootstrap.sh`.

## Chezmoi apply path

`bootstrap.sh` was replaced by
`run_onchange_before_install-packages.sh.tmpl`. Manifest checksums are inlined
so changing `packages/*` re-runs the script on the next apply. Manual README
steps still exist: `chezmoi init`, `chezmoi diff`, then
`chezmoi apply --interactive`.
