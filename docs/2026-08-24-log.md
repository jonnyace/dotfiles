# 2026-08-24

## One-line installer

Added `install.sh` so a new macOS or Arch Linux machine can bootstrap this
repository with:

```sh
curl -fsSL https://raw.githubusercontent.com/jonnyace/dotfiles/main/install.sh | bash
```

The script installs missing prerequisites, clones or updates the Chezmoi source
from `jonnyace/dotfiles`, and runs `bootstrap.sh`. It does not apply dotfiles;
`chezmoi diff` and `chezmoi apply --interactive` stay a review step.

README gained a one-line section at the top of setup. The existing per-platform
manual commands were kept.
